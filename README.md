# Pdf_scan_and_ocr

Настольное GUI-приложение для Windows: конвертация отсканированных PDF в PDF/A с поиском по тексту, RAG-база и семантический поиск в табличном виде.

## Документация

- [Техническое задание (ТЗ)](docs/ТЗ_PDF_OCR_RAG.md) — полная спецификация проекта для разработки

## Модули (план)

1. **Обработка PDF** (два этапа):
   - **Этап 1 — OCR:** Qwen3-VL, PDF/A, Markdown, метаданные → каталог `pending_vectorization/`
   - **Этап 2 — Embedding:** Qwen3-Embedding, поочерёдная векторизация → каталог `documents/`
   - Серверы моделей запускаются **вручную**; **одновременно активна только одна модель** (на этом же ПК или по LAN)
2. **Управление RAG** — метаданные, подтверждение, re-embedding, синхронизация
3. **Поисковый модуль** — семантический поиск без LLM: запрос → таблица результатов

## Статус

Проект на стадии проектирования. Реализация — по этапам, описанным в ТЗ.
