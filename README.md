# Pdf_scan_and_ocr

Настольное GUI-приложение для Windows: конвертация отсканированных PDF в PDF/A с поиском по тексту, RAG-база и семантический поиск в табличном виде.

## Документация

- [Техническое задание (ТЗ)](docs/ТЗ_PDF_OCR_RAG.md) — полная спецификация проекта для разработки

## Модули (план)

1. **Обработка PDF** — OCR (Qwen3-VL), PDF/A, Markdown, автоматическое извлечение номера и наименования документа, подтверждение метаданных пользователем, векторизация (Qwen3-Embedding)
2. **Управление RAG** — метаданные (номер, наименование), подтверждение метаданных, re-embedding, синхронизация файлов и vectorstore
3. **Поисковый модуль** — семантический поиск без LLM: строка запроса → таблица результатов (номер, наименование, вырезка текста, ссылка на PDF/A)

## Статус

Проект на стадии проектирования. Реализация — по этапам, описанным в ТЗ.
