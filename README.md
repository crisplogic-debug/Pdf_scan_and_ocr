# Pdf_scan_and_ocr

Настольное GUI-приложение для Windows: конвертация отсканированных PDF в PDF/A с поиском по тексту, RAG-база и LLM-поисковый агент.

## Документация

- [Техническое задание (ТЗ)](docs/ТЗ_PDF_OCR_RAG.md) — полная спецификация проекта для разработки

## Модули (план)

1. **Обработка PDF** — OCR (Qwen3-VL), PDF/A, Markdown, векторизация (Qwen3-Embedding)
2. **Управление RAG** — метаданные, re-embedding, синхронизация файлов и vectorstore
3. **Поисковый агент** — чат с RAG, streaming-ответы, ссылки на документы

## Статус

Проект на стадии проектирования. Реализация — по этапам, описанным в ТЗ.
